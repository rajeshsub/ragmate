# ragmate: Domain Glossary

## Document

A file uploaded by the user for querying. Supported formats: PDF, TXT, Markdown, DOCX.
A Document has a unique ID (UUID), a filename, and a chunk count.
A Document is deleted when the user explicitly requests removal; deletion removes all associated Chunks and their vectors.

## Chunk

A sub-section of a Document produced by the chunking pipeline. A Chunk is the atomic unit stored in the vector store.
Chunks are not exposed directly through the API; they surface only as excerpts within Source references.

## Embedding

A fixed-size float vector representing the semantic meaning of a Chunk or Query.
Embeddings are produced by the `text-embedding-004` model and stored alongside their Chunks in ChromaDB.

## Query

A natural-language question submitted by the user. A Query is embedded at request time and used to find relevant Chunks via cosine similarity search.

## Answer

The text response generated by the LLM based on retrieved Chunks. An Answer is always grounded in the provided context; the system instructs the LLM not to answer from prior knowledge.

## Source

A reference returned alongside an Answer. A Source identifies the Document and Chunk from which a piece of evidence was drawn, including a relevance score and a short excerpt.

## Vector Store

ChromaDB persisted to disk. Owns both Chunk vectors and Document metadata. The single source of truth for all stored data; there is no separate database.

## Ingestion Pipeline

The sequence: parse → chunk → embed → store. Produces a Document record and its Chunks in one atomic operation.

## Retrieval Pipeline

The sequence: embed query → vector search → generate. Produces an Answer with Sources.
